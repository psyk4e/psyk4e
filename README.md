I build iOS and Android apps and help teams ship them. At **Grupo Humano**, I work on mobile apps for insurance intermediaries and policyholders, support functional and regression testing with QA, and coordinate releases with engineering and business teams. I also build backend services and automate recurring work with AI agents and reusable skills.

## Selected work

- **[Mobile build delivery at Grupo Humano](https://psyk4e.vercel.app/featured-projects)** — Migrated React Native from 0.65 to 0.80.2. Built Azure DevOps pipelines that cut deploy time from **45 to 18 minutes** and helped integrate an internal platform so more teammates could generate QA builds.
- **[OpenRD for iOS and Android](https://apps.apple.com/do/app/openrd/id6741169848)** — Built the web and mobile apps with Next.js and Expo. Both mobile apps share **95% of their code**. Integrated the Zoom SDK for communication and Amazon S3 for document storage.
- **[Electronic invoicing at Telenord](https://psyk4e.vercel.app/professional-experience)** — Built backend modules for electronic invoicing with the Dominican tax authority. Optimized SQL Server queries to cut report generation from **45 to 8 seconds**.
